# Centro Dental Dra. Rosanna Méndez

Sitio web oficial y landing page de alta conversión para el **Centro Dental Dra. Rosanna Méndez** en Santo Domingo, República Dominicana.

## Características
- Diseño moderno, elegante y de grado médico editorial.
- Perfectamente responsivo en Mobile, Tablet y Desktop.
- Slider interactivo "Antes y Después" para casos clínicos.
- Integración directa de agendamiento vía WhatsApp (`(809) 662-6547`).
- Optimizado para despliegue instantáneo en Vercel.

## Despliegue en Vercel
1. Conecta este repositorio en tu cuenta de Vercel.
2. Framework Preset: **Other**.
3. Haz clic en **Deploy**.
